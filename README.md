# 맞혀볼래? (가칭) — AI 맞히기 게임 1차 버전

업무 원장 "AI game App" 블록의 첫 결과물이에요. 기획 분석(`D:\Taeho\reports\2026-10-30\game\report.md`)의 결론대로
**공통 퀴즈 뼈대를 먼저 만들고, 그 위에 1순위 게임 "명대사 듣고 작품 맞히기"를 올렸어요.**
2순위 "노래 → AI 그림 → 제목 맞히기"는 화면과 데이터 구조만 만들고 샘플 그림으로 흐름을 확인했어요.

- **아직 배포하지 않았어요.** 인터넷 주소도 없어요. 이 컴퓨터에서만 열려요.
- **DB 를 쓰지 않아요.** 문제는 저장소 안의 JSON 파일, 점수 기록은 각자 기기(localStorage)에만 남아요.
- **돈 드는 API 를 부르지 않아요.** 음성은 휴대폰·PC 에 원래 들어 있는 음성 읽기 기능(무료)을 써요. API 키도 필요 없어요.

## 1. 지금 만든 것

### 공통 퀴즈 뼈대 (앞으로 만들 게임이 모두 함께 씀)

| 화면 | 하는 일 |
|---|---|
| 홈 | 퀴즈 묶음 목록 (인기순·최신순), 내 최고 점수 |
| 묶음 시작 | 진행 방법, 점수 규칙, 소리 확인(명대사), 내 최고 기록 |
| 문제 | 그림 또는 재생 버튼 · 정답 입력(Enter 로 제출) · 힌트 · 건너뛰기 · 기회 2번 |
| 정답 공개 | 정답/오답, 공식 제목, 연도·장르, **출처 표시**, 내가 낸 답 |
| 결과 | 점수, 맞힌 개수, 걸린 시간, 공유 문구 복사, **공유 카드 이미지**(저장·공유), 다시 하기 |

- **채점**: 띄어쓰기·문장부호·대소문자를 무시해요. 줄임말·영어 제목도 정답으로 인정해요.
  예) "범죄와의 전쟁" = "범죄와의전쟁" = "범죄와의 전쟁: 나쁜놈들 전성시대" = "Nameless Gangster" = "범죄와의 전쟁 (2012)"
  한두 글자 틀리면 "아까워요!"라고만 알려 주고 정답 처리는 하지 않아요("범죄도시2"와 "범죄도시3"이 같아지면 안 되니까요).
- **힌트**: 초성(ㅂㅈㅇㅇ ㅈㅈ) → 연도 → 장르 순서. 게임마다 추가 힌트 하나(명대사는 "대사 보기", 노래는 "그림 설명 보기").
- **점수**: 바로 맞히면 100점, 두 번째 기회에 맞히면 70점, 힌트 하나에 −20점, 추가 힌트 −10점, 맞히면 최소 20점.
- **공유 칸**: 🟩 힌트 없이 한 번에 · 🟨 힌트나 두 번째 기회로 · 🟥 틀림 · ⬜ 건너뜀 (카톡에 붙여 넣기 좋게)
- 휴대폰 화면 기준으로 만들었고, 키보드만으로도 끝까지 할 수 있어요(입력칸 이름표, 초점 이동, Enter 제출, 화면낭독기 안내).

### 게임 ① 명대사 듣고 작품 맞히기 (`quote_tts`) — 지금 바로 할 수 있어요

- 영화 15문제 · 드라마 15문제. 문제마다 **짧은 대사 한 줄**을 기기의 **일반 한국어 TTS 음성**이 읽어요(여성 음성이 있으면 먼저 골라요).
- 다시 듣기, 속도(느리게·보통·빠르게) 조절. 대사 글자는 정답을 확인한 뒤에만(또는 "대사 보기" 힌트로) 보여요.
- 기기에 한국어 음성이 없으면 안내 문구를 띄우고 대사를 글자로 보여 줘요(감점 없음).

### 게임 ② 노래 → AI 그림 → 제목 맞히기 (`song_image`) — 자리만 만들어 둠

- 데이터 구조와 그림 문제 화면이 동작해요. 샘플 5문제는 **코드로 그린 단순한 그림**이고 화면에 "샘플 그림 · AI 생성 아님"이라고 표시돼요.
- 실제 앨범 표지·뮤직비디오 장면·가사는 쓰지 않았어요.

### 지키는 원칙 (기획 보고서의 법적 위험 정리를 그대로 반영)

- 음성은 **일반 TTS 음성만**. 배우 목소리 복제·흉내·"OO처럼" 연출 없음. 음높이·속도로 특정인을 흉내 내지 않아요.
- **배우 이름을 문제·화면·홍보 문구 어디에도 쓰지 않아요.**
- 대사는 **한 문제에 한 줄**(60자 이하, 자동 검사). 정답 공개 때 **작품명·연도를 출처로 표시**해요.
- 영화 스틸컷·포스터·원본 음성은 쓰지 않아요. 화면은 글자와 직접 만든 그래픽뿐이에요.
- 화면 아래에 "대사는 출처 표시 목적의 짧은 인용이에요" 안내와 **"AI·TTS 음성"** 표시를 붙였어요.
- 노래 그림은 가사를 쓰지 않고, 실제 출시 그림에는 **"AI 생성"** 표시를 붙이도록 데이터에 칸을 만들어 두었어요.

## 4. 노래 그림 게임을 진짜로 만들려면

1. **그림 API 결정** (대표 결정): 보고서 기준 gpt-image-1-mini 약 15원/장, Gemini 2.5 Flash Image 약 55원/장. 후보 4장이면 문제당 60~220원, 100문제에 약 6천~2.2만원. [가격은 계약 전 공식 페이지에서 재확인]
2. **API 키는 서버(Cloudflare Workers)에만** 두고, 화면 쪽에는 절대 넣지 않아요.
3. **프롬프트에는 우리가 쓴 분위기 설명만** 넣어요(`sceneDescription`). 가사·가수 이름·앨범 표지 묘사는 넣지 않아요.
4. **사람이 후보 4장 중 1장을 골라요** — "맞힐 수 있지만 너무 쉽지 않은" 그림. 이 고르기 화면(관리자 검수 화면)이 필요해요.
5. 고른 그림은 **Cloudflare R2 에 한 번만 저장**하고 계속 재사용 → 플레이할 때마다 돈이 들지 않아요.
6. 데이터는 `image: { kind: "file", src, alt, aiModel }` 로 넣으면 화면에 자동으로 **"AI 생성 · 모델 이름"** 표시가 붙어요.
7. 정답 공개에 공식 뮤직비디오 링크(`officialLink`)를 붙여요. 음원은 우리 서버에 두지 않아요.
8. 첫 30~50문제로 정답률을 재고 난이도를 맞춘 뒤 늘려요.

## 7. 알려진 한계

- 인기순은 지금 운영자가 정한 순서예요(가짜 플레이 수는 보여 주지 않아요).
