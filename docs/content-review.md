# 문제 검수표 — 출시 전 사람이 꼭 확인

작성 2026-11-11 · 대상 `src/data/*.json` 의 문제 35개 (영화 15 · 드라마 15 · 노래 그림 샘플 5)

모든 문제에 `"needsReview": true` 가 붙어 있어요. 아래 표를 하나씩 확인하고, 맞으면 JSON 에서 그 문제의 값을 `false` 로 바꿔 주세요.
틀린 곳이 있으면 대사·제목·연도를 고치거나 문제를 빼 주세요. 고친 뒤에는 `npm test` 로 형식 검사를 돌려요.

## 확인 방법

1. **대사**: 실제 장면(정식 VOD·DVD)에서 글자 하나까지 맞는지. 인터넷에 도는 문구가 원래 대사와 다른 경우가 많아요.
2. **작품명**: 영화는 KMDb(한국영화데이터베이스)·영진위 KOBIS, 드라마는 방송사 공식 홈페이지 표기.
3. **연도**: 영화는 개봉 연도, 드라마는 첫 방송(공개) 연도로 통일했어요.
4. **한 줄·짧게**: 대사는 한 문제에 한 줄만, 60자 이하 (자동 검사). 길면 줄여요.
5. **배우 이름은 어디에도 넣지 않아요** (문제·정답 화면·홍보 문구 모두). 지금 데이터에도 배우 이름은 없어요.

확신도: **상** = 대사·작품·연도 모두 확실 · **중상** = 작품·연도는 확실, 대사 글자(어순·사투리)만 확인 필요 · **중** = 대사 표현을 꼭 확인
